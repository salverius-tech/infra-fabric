# Canonical model review register

This register records value-free review categories for canonical site completion. It is not an operator input file and contains no site values or credentials.

## Secret or protected inputs

Protected logical paths must be declared in the encrypted site bundle and delivered only through approved transient consumers. Missing paths remain a review item.

## Behavior or configuration without a typed owner

Every canonical field requires a typed schema owner, catalog binding, or an explicit reviewed exemption.

## Ambiguous or destructive inputs

Conflicting ownership, destructive resource behavior, replacements, and stateful changes require a reviewed plan and explicit approval.

## Migration-only or unsupported inputs

Inputs without a current canonical owner are review items. They must not become a second authoring surface or be silently inferred by normal lifecycle commands.
