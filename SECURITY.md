# Security policy

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting for this repository:

<https://github.com/salverius-tech/infra-fabric/security/advisories/new>

Do not disclose suspected vulnerabilities in public issues or discussions.
Include the affected paths, a concise impact description, and safe reproduction
steps. Do not include live credentials, private site values, decrypted secrets,
state files, or infrastructure endpoints in a report.

If the private reporting page is unavailable, do not publish the report. Contact
a repository maintainer through a private channel and request an alternate
reporting path.
